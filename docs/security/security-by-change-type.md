# Segurança por tipo de mudança

## Login / auth

- [ ] Senha nunca em log
- [ ] Rate limit brute force
- [ ] Sessão/token seguro
- [ ] Threat model se `sensitive: true`

## API

- [ ] Autorização por recurso
- [ ] Validação schema
- [ ] Erros padronizados (error-catalog)

## Upload

- [ ] Tipo/tamanho validados
- [ ] Armazenamento isolado
- [ ] Scan malware se aplicável

## UI

- [ ] XSS: escape/sanitize
- [ ] Dados sensíveis não em URL/localStorage indevido
