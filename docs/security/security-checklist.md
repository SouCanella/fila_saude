# Checklist de segurança — por entrega

- [ ] Autenticação e autorização corretas
- [ ] Validação e sanitização de entrada
- [ ] Sem exposição de dados sensíveis em resposta/log
- [ ] Erros sem detalhes internos ao cliente
- [ ] Secrets fora do código
- [ ] Dependências sem CVE crítico/alto
- [ ] CORS e headers de segurança (se API web)
- [ ] Rate limit onde aplicável

Issue **crítica** ou **alta** bloqueia merge.
