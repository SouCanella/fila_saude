# i18n — FilaSaúde Brasil

Gerado no bootstrap (bloco K — 2026-06-09).

## Modo single language (MVP)

`i18n.enabled: false` — idioma único: **pt-BR**.

Documentação, UI e conteúdo legal em português brasileiro.

HTML mock: `<html lang="pt-BR">` em todas as telas de `design-references/screens/`.

## Modo multilíngue (pós-MVP)

Se `i18n.enabled: true`:

- Locales candidatos: `es-ES` (expansão fronteiras), `en-US` (turismo)
- Estratégia de chaves: namespaces por tela (`onboarding`, `map`, `hospital`)
- Fallback: `pt-BR`
- Next.js: `next-intl` ou equivalente

## Conteúdo sensível

Avisos médicos e LGPD devem ser traduzidos por profissional — não usar tradução automática para textos legais.
