Saúde da qualidade

Visão executiva e técnica: índice de saúde, cobertura, cenários E2E em linguagem de negócio e rastreio REQ → testes. Complementa o painel de tempo (process-metrics).

Para gestores

  • Índice de saúde (0–100) — nota consolidada dos testes obrigatórios.
  • E2E — fluxos reais (persona, passos, resultado esperado); toggle Cards ou Tabela.
  • Integração API — inclui testes de contrato OpenAPI na mesma camada.
  • Filtros globais — requisito, status, prioridade e tipo (funcional/NFR).
  • Riscos e gaps — requisitos que ainda não estão prontos para release.
  • Status traduzidos: Aprovado, Falhou, Planejado, etc.

Executar testes pelo painel

Com make quality-demo-serve (porta 8093), use Executar testes — simula nova suite e atualiza o JSON. No template virgem, o botão apenas reconstrói o painel (make quality-build).

Fontes de dados

  • docs/backlog/mvp-backlog.md — req_kind functional | non_functional
  • docs/specs/REQ-*.md — camadas, plano TDD e tabela E2E enriquecida
  • docs/traceability-matrix.md
  • docs/meta/quality-runs/latest.json (CI) ou manual.yaml

Comandos

make quality-build
make quality-serve      # :8092 + API refresh
make quality-demo-serve # :8093 + API run-tests (demo)
